# VillageInTheShade-SaveToEN

> **ไทย:** ม็อดช่วยแปลงเซฟเกม *Village in the Shade* (จากภาษาญี่ปุ่นหรือภาษาอื่นๆ) ให้เล่นเป็นภาษาอังกฤษ และเมื่อกดนอนเซฟทับ เซฟนั้นจะกลายเป็นเซฟอังกฤษถาวร  
> **EN:** A lightweight plugin for *Village in the Shade* that lets you load JP (or any non-EN) saves in English — sleep once to save, and your save permanently converts into an EN save!

---

## ม็อดนี้ทำอะไรได้? (แบบเข้าใจง่าย)

มีเซฟภาษาญี่ปุ่นหรือภาษาอื่น แต่อยากเล่นต่อเป็น **ภาษาอังกฤษ** ใช่ไหม?
1. ลงม็อดนี้แล้วกดเข้าเซฟเดิมได้เลย เกมจะเปิดเป็นภาษาอังกฤษให้เล่นทันที (ภาพ เมนู และข้อความเป็นภาษาอังกฤษครบ)
2. **พอกดนอนเพื่อเซฟทับ 1 ครั้ง ไฟล์เซฟนั้นจะกลายเป็น "เซฟอังกฤษ" แบบถาวร**
3. หลังจากเซฟเสร็จ ถ้าอยากถอดม็อดออกแล้วเล่นเกมตัวเปล่าต่อ เซฟนั้นก็จะยังเป็นภาษาอังกฤษเหมือนเดิมครับ!

### จุดเด่น
- รองรับเซฟภาษาญี่ปุ่น (JP) และเซฟภาษาอื่นๆ ทั้งหมด
- ไม่ทำลายไฟล์เซฟ ไม่ยุ่งกับไฟล์ `.dat` หรือไฟล์ภาพของเกม
- ใช้ **AoB Signature Scanner** ค้นหาจุดแก้ใน `village.exe` อัตโนมัติ (รองรับแพตช์อัปเดตเกมทั่วไปได้โดยไม่ต้องแก้โค้ดใหม่)

## วิธีติดตั้งและใช้งาน (3 ขั้นตอนง่ายๆ)

1. **ดาวน์โหลดไฟล์ม็อด:** ไปที่ [`output/Village_SaveJP_to_EN_v1.0.zip`](output/Village_SaveJP_to_EN_v1.0.zip) แล้วกด **Download raw file**
2. **แตกไฟล์ลงโฟลเดอร์เกม:** แตกไฟล์ทั้งหมดไปวางในโฟลเดอร์เดียวกับ `village.exe` ให้ได้โครงสร้างนี้:
   ```text
   Village in the Shade\
   ├── village.exe
   ├── winmm.dll
   └── Mods\
       └── SaveJPtoEN\
           ├── save_jp_to_en.dll
           └── save_jp_to_en.ini
   ```
3. **เปิดเกมและกดนอน:**
   - เปิดเกมตามปกติ แล้วกดเลือกโหลดเซฟญี่ปุ่น (หรือเซฟภาษาอื่น) ที่ต้องการ → เกมจะโหลดขึ้นมาเป็นภาษาอังกฤษทันที
   - เล่นแล้วกด **นอน (Sleep)** เพื่อเซฟทับ 1 ครั้ง → เสร็จสิ้น! เซฟจะถูกบันทึกเป็น EN ถาวร

## วิธีปิดชั่วคราว / ถอนการติดตั้ง

- **ปิดชั่วคราว:** เปิดไฟล์ `Mods\SaveJPtoEN\save_jp_to_en.ini` แล้วเปลี่ยน `enabled=1` เป็น `enabled=0`
- **ลบม็อดออก:** ลบ `winmm.dll` และโฟลเดอร์ `Mods\SaveJPtoEN\` ทิ้งได้เลย (เซฟที่กดนอนเซฟทับไปแล้วจะยังเป็น EN เหมือนเดิม)

### หมายเหตุ
- **ห้ามวางทับกับม็อดไทยในโฟลเดอร์เดียวกัน** เพราะม็อดไทยใช้ตัวโหลดชื่อ `winmm.dll` เหมือนกัน หากใช้เครื่องเดียวกันให้สลับหรือสำรอง `winmm.dll` เดิมไว้ก่อน
- หากต้องการเช็กว่าปลั๊กอินทำงานครบทุกจุดหรือไม่ สามารถเปิดดูไฟล์ `Mods\SaveJPtoEN\save_jp_to_en.log` หลังเปิดเกมได้

## สำหรับนักพัฒนา / วิธีคอมไพล์เอง (Build from Source)

- คอมไพเลอร์ที่ใช้: [Zig](https://ziglang.org/) (`zig cc` x64) + Python 3
- รันไฟล์ [`build.bat`](build.bat) เพื่อคอมไพล์ `bin/save_jp_to_en.dll`, `bin/winmm.dll` และสร้างไฟล์ ZIP ใหม่ใน `output/`
